# 深度学习实践 3 - 智能优化方法的自主编写与和现有算法的对比

## 第一步：零库算法手写复现

- **目标**：不使用任何现成优化库，仅依赖语言原生基础语法与随机数函数。
- **算法 1：遗传算法 (GA)**
  - 手写“轮盘赌”或锦标赛选择算法；实现单点交叉及位变异逻辑。
- **算法 2：粒子群算法 (PSO)**
  - 用结构体/多维列表维护位置与速度；手写位置、速度物理更新公式；硬编码越界截断。

## 第二步：基准测试与收敛记录

- **测试数据集**：
  标准 TSPLIB 数据集（如 `berlin52` 2D 旅行商问题，离散问题）。
- **数据采集**：记录每代（Iteration）的最佳适应度，导出数据并绘制**收敛轨迹曲线**。

## 第三步：与标准库对齐

- **工具选型**：使用 Python 领域的 `scikit-opt` 或 `DEAP` 开源库。
- **严格对齐**：确保标准库中**种群规模**、**迭代次数**、**交叉/变异率**等控制参数与自写算法完全一致。
