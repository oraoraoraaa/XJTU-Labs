\section{实验概述}

本实验围绕 APPA-REAL 人脸数据集完成端到端表观年龄预测。课程要求的核心任务是实现 \texttt{AgeNet(nn.Module)}：模型输入一张 $128\times128$ RGB 人脸图像，输出 0 到 100 岁共 101 个类别的 logits，并在验证集上用平均绝对误差（MAE）选择最优模型。项目同时补充实现了 DenseNet-121 与 ViT-B/16 两个从零训练的拓展模型，用于观察卷积式结构与 Transformer 式结构在本数据规模下的表现差异。

\section{实验目标}

本次实验的目标可以概括为以下六点：
\begin{enumerate}
  \item 理解年龄估计中“分类训练 + 回归评价”的建模方式；
  \item 使用 PyTorch 按课程给定结构实现 \texttt{AgeNet}；
  \item 完成 APPA-REAL 图像数据读取、预处理、训练集增强与测试集预测；
  \item 以验证集 MAE 作为主要指标，保存验证性能最优的模型权重；
  \item 对训练日志中的收敛趋势、模型选择与误差来源进行分析；
  \item 在同一评价方式下比较 AgeNet、DenseNet-121 与 ViT-B/16 的实验现象。
\end{enumerate}

\subsection{预处理与增强}

数据管线在 \texttt{helperT.py} 的 \texttt{FaceDataset} 中实现。输入图像先由 OpenCV 读取，统一缩放到 $128\times128$，再由 BGR 转为 RGB，并经过 \texttt{ToTensor} 与均值、标准差均为 0.5 的归一化，最终输入范围大致落在 $[-1,1]$。

训练集还加入了多种增强策略：加性高斯噪声、高斯模糊、$-20^\circ$ 到 $20^\circ$ 的随机旋转、小幅缩放和平移、Gamma 对比度变化以及随机水平翻转。对于训练标签，程序会根据年龄标注标准差加入高斯扰动，再四舍五入并裁剪到 0 到 100 岁。这一处理利用了 APPA-REAL 标注标准差中蕴含的不确定性，可降低模型对单一整数标签的过拟合。

\section{方法设计}

\subsection{分类训练与期望回归}

年龄估计可以直接看作回归问题，也可以转化为分类问题。本实验采用后者：网络输出 101 维 logits，每一维对应一个年龄类别。训练阶段使用交叉熵损失；评价与预测阶段先用 softmax 得到年龄概率分布，再计算概率期望作为连续年龄估计。

\[
P(a|x)=\mathrm{softmax}(f(x))_a,
\qquad
\hat{y}=\sum_{a=0}^{100}a\cdot P(a|x).
\]

这种方式的优点是训练信号来自稳定的分类损失，而最终输出仍能表达连续年龄。与直接取最大概率类别相比，期望回归可以利用整个概率分布，减少整数类别之间的跳变。

\subsection{评价指标}

实验使用平均绝对误差（MAE）评价预测年龄与真实年龄的偏差：

\[
\mathrm{MAE}=\frac{1}{N}\sum_{i=1}^{N}|\hat{y}_i-y_i|.
\]

MAE 的单位是“岁”，数值越小表示模型平均预测偏差越低。由于测试集没有公开真实年龄标签，项目只能对测试集生成预测文件；可量化比较主要基于验证集 MAE。

\subsection{AgeNet 网络结构}

AgeNet 是一个 VGG 风格的卷积网络。输入为 $3\times128\times128$，每经过一次 $2\times2$ 最大池化，空间尺寸减半，最终得到 $512\times4\times4$ 的特征图。展平后的 8192 维特征经过两个 4096 维全连接层，最后输出 101 个年龄类别。

\begin{table}[H]
  \centering
  \caption{AgeNet 网络结构}
  \label{tab:agenet}
  \begin{tabularx}{\textwidth}{p{2.1cm}X p{3.2cm}}
    \toprule
    模块 & 层结构 & 输出尺度 \\
    \midrule
    Block 1 & \texttt{Conv 7x7, 3->64} + ReLU + MaxPool & $128^2 \to 64^2$ \\
    Block 2 & \texttt{Conv 5x5, 64->128} + ReLU + \texttt{Conv 5x5, 128->128} + ReLU + MaxPool & $64^2 \to 32^2$ \\
    Block 3 & 3 个 \texttt{3x3} 卷积，通道 \texttt{128->256->256->256} + MaxPool & $32^2 \to 16^2$ \\
    Block 4 & 3 个 \texttt{3x3} 卷积，通道 \texttt{256->512->512->512} + MaxPool & $16^2 \to 8^2$ \\
    Block 5 & 3 个 \texttt{3x3} 卷积，通道 \texttt{512->512->512->512} + MaxPool & $8^2 \to 4^2$ \\
    Classifier & Flatten + \texttt{8192->4096->4096->101} & 101 类 logits \\
    \bottomrule
  \end{tabularx}
\end{table}

\subsection{拓展模型}

为了观察不同结构在同一数据管线下的表现，项目额外训练了两个对比模型：
\begin{itemize}
  \item \textbf{DenseNet-121}：使用 \texttt{torchvision.models.densenet121(weights=None)}，将最后分类层替换为 101 类输出。由于训练从随机初始化开始，DenseNet 的密集连接有助于梯度传播，但没有 ImageNet 预训练的先验优势。
  \item \textbf{ViT-B/16}：使用 \texttt{torchvision.models.vit\_b\_16(weights=None)}，输入在模型内插值到 $224\times224$。Transformer 对数据规模与训练策略更敏感，从零训练时更容易出现收敛不足。
\end{itemize}

\section{关键实现}

\subsection{AgeNet 模型定义}

以下片段概括了主模型的实现方式。完整代码位于 \texttt{agenet/age\_net.py}。

\begin{lstlisting}[caption={AgeNet 核心结构节选}]
class AgeNet(nn.Module):
    def __init__(self, num_classes=101):
        super(AgeNet, self).__init__()
        self.features = nn.Sequential(
            nn.Conv2d(3, 64, kernel_size=7, padding=3),
            nn.ReLU(inplace=True),
            nn.MaxPool2d(kernel_size=2, stride=2),
            nn.Conv2d(64, 128, kernel_size=5, padding=2),
            nn.ReLU(inplace=True),
            nn.Conv2d(128, 128, kernel_size=5, padding=2),
            nn.ReLU(inplace=True),
            nn.MaxPool2d(kernel_size=2, stride=2),
            # three 3x3-conv stages follow, ending with 512 channels
        )
        self.avgpool = nn.AdaptiveAvgPool2d((4, 4))
        self.classifier = nn.Sequential(
            nn.Flatten(),
            nn.Linear(512 * 4 * 4, 4096),
            nn.ReLU(inplace=True),
            nn.Dropout(0.5),
            nn.Linear(4096, 4096),
            nn.ReLU(inplace=True),
            nn.Dropout(0.5),
            nn.Linear(4096, num_classes),
        )
\end{lstlisting}

\subsection{训练与验证流程}

训练脚本位于 \texttt{agenet/train\_ageNet.py}。模型使用 SGD 优化器，学习率为 0.001，动量为 0.9，无权重衰减。每个 epoch 结束后在验证集计算 MAE；当 MAE 刷新时保存 \texttt{best\_age\_net.pth}。

\begin{lstlisting}[caption={验证阶段的概率期望与 MAE 计算}]
ages = torch.arange(0, 101).float().to(device)
with torch.no_grad():
    for _, (y, x) in enumerate(val_loader):
        outputs = model(x.to(device).float())
        probs = torch.softmax(outputs, dim=1)
        pred_age = (probs * ages).sum(dim=1)
        predsVal.append(pred_age.cpu().numpy())
        gtsVal.append(y.cpu().numpy())

mae = np.mean(np.abs(predsVal - gtsVal))
\end{lstlisting}

\subsection{结果分析}

从结果看，AgeNet 在第 1 轮 MAE 较高，但随后快速下降，并在第 89 轮达到 7.3164 的最佳验证 MAE。说明该 VGG 风格结构虽然没有预训练权重，但与 $128\times128$ 人脸输入和 101 类年龄分类目标匹配度较高，训练后期仍能继续挖掘年龄相关的局部纹理与脸部形态特征。

DenseNet-121 的收敛更平滑，最优 MAE 为 7.6932，略弱于 AgeNet。由于本实验中 DenseNet 也是从随机初始化训练，密集连接带来的特征复用优势未能完全抵消数据规模有限和缺少预训练先验的影响。

ViT-B/16 的 MAE 长期停留在 11 左右，最终最优值为 11.0396。这与视觉 Transformer 的训练特性相符：当没有大规模预训练和充分数据时，ViT 很难像卷积网络那样利用局部归纳偏置快速学习稳定的人脸年龄特征。因此，在本实验设置下，ViT 更适合作为“从零训练不充分”的对照，而不是最终提交模型。

\section{问题讨论与改进方向}

\subsection{误差来源}

表观年龄本身具有主观性，同一张人脸的感知年龄可能受表情、光照、姿态、妆容、分辨率和标注者偏好影响。APPA-REAL 提供的 \texttt{apparent\_age\_std} 正说明年龄标签并非严格的确定值。模型即使在验证集上达到较低 MAE，仍可能在儿童、老年人以及遮挡较强的人脸上出现更大偏差。

此外，日志中的 loss 是每个 epoch 中 batch loss 的累加和，而不是平均 loss。因此 loss 的绝对数值不适合直接与常见的单 batch 平均损失比较，更适合用于观察同一训练过程内部的下降趋势。

\subsection{可改进方案}

后续可以从以下方向提升结果：
\begin{itemize}
  \item 引入学习率调度，例如 StepLR、CosineAnnealing 或 warmup 策略，使后期优化更稳定；
  \item 使用 ImageNet 预训练的 ResNet、DenseNet 或 ConvNeXt，再微调 101 类年龄头；
  \item 将交叉熵与标签分布学习结合，把年龄标准差显式转为软标签；
  \item 对年龄段分布进行重采样或损失重加权，缓解常见年龄段和稀有年龄段的不均衡；
  \item 增加验证集误差可视化，例如按年龄段统计 MAE，以定位模型在不同年龄区间的弱点。
\end{itemize}

\section{总结}

本实验完成了 APPA-REAL 表观年龄预测的完整流程：数据读取与增强、AgeNet 网络实现、分类训练、验证集 MAE 选择最优模型，以及测试集年龄预测输出。主模型 AgeNet 在第 89 个 epoch 达到最佳验证 MAE 7.3164，说明课程要求的 VGG 风格卷积结构可以在从零训练的条件下形成较稳定的年龄估计能力。

拓展实验表明，在相同数据管线和无预训练设置下，DenseNet-121 的最佳 MAE 为 7.6932，接近但略弱于 AgeNet；ViT-B/16 的最佳 MAE 为 11.0396，反映出 Transformer 结构在小规模数据和无预训练条件下不易充分收敛。综合准确性、实现稳定性与课程目标，AgeNet 是本项目中最合适的最终提交模型。
