# 学生框架接口契约

工具名称和参数在server.py保持原注册方式，实际发现得到的tool_schema.json为调用参数规范。统一入口16工具；独立memory/filesystem/process分别7/5/6个，包含重复的get_time。能够发现工具仅说明接口已注册。

每个工具返回以下信封。学生可用lab_common.result封装，禁止用ok=true掩盖未实现：

```json
{
  "ok": false,
  "kind": "status",
  "sampled_at": "真实采样或返回时间，ISO格式，带时区",
  "platform": "Linux",
  "source": "get_process_tree",
  "units": {},
  "data": null,
  "error": "NOT_IMPLEMENTED",
  "limitations": [],
  "task": "P1",
  "location": "students/process.py:get_process_tree",
  "message": "TODO P1：请完成对应函数，当前未执行该功能。"
}
```

实际time/platform由框架生成，上例是结构示意。成功时error=None、data为含观测或模拟结果的字典。真实采集kind=observation，算法kind=simulation，通信或未完成kind=status。source是数据来源，不是模型结论；模型解释属于推断。

|调用入口|输入|输出主体与任务|
|---|---|---|
|get_memory_info|无|内存total/available/used/free/percent、swap，已提供|
|list_top_processes|limit=5|processes、excluded，M1|
|get_process_memory|pid必填、max_maps=12|memory、maps、maps_partial，M2|
|analyze_memory_patterns|pages可选|复用/相邻指标，M3|
|simulate_page_fault|algorithm、frames、pages、seed|逐步页框、缺页、命中，A1|
|sample_process_memory|pid必填、samples、interval|samples与delta，M4|
|get_filesystem_info|path="."|capacity、inode，F1|
|analyze_file_distribution|path、max_files|分类、大小桶、partial，F2|
|trace_file_access|path、seconds|events、truncated、overflow，F3|
|simulate_disk_allocation|strategy、blocks、operations、block_size|files、逐步log和空间指标，A3|
|get_process_tree|limit|nodes、omitted，P1|
|monitor_context_switches|pid可选、seconds|实际时长、计数差、count/s，P2|
|analyze_scheduling|seconds|raw_delta_ticks、各CPU比例，P3|
|get_process_schedstat|pid必填、seconds|运行/等待ns、是否启用、可为空均值，P4|
|simulate_scheduler|algorithm、quantum、jobs、boost_interval|时间线、各任务指标与均值，A2|

完整字段、数值范围、异常和测量边界写在对应学生函数docstring，参数边界另见server.py及发现的Schema。基础get_time在sampled_at返回真实UTC时间。

输入兼容既有教学规范：页面策略用algorithm，调度任务用jobs及id/arrival/burst或bursts，分配用operations。学生可补内部函数，不随意改外部参数名或删除返回字段。

## 错误与退出状态

StudentTaskPending由Server转换为NOT_IMPLEMENTED，不伪造data。权限/参数错误由提供的包装转换为ok=false及具体原因；不支持的平台由学生明确返回UNSUPPORTED_PLATFORM。内核未启用schedstats时，成功的采集结果可以含None均值，需说明局限。

mcp_check默认输出MCP外层对象，--unwrap输出内层。工具层TODO通常是协议成功、业务未完成，要检查内层error。Host trace[].result已经是内层，无需再找content。

|命令|0|2|其他非零|
|---|---|---|---|
|mcp_check|成功/发现|NOT_IMPLEMENTED|协议或其他功能错误|
|validate_lab|所选阶段通过|存在待实现任务|检查失败或平台不支持|
|host|completed|not_implemented|failed/partial/empty_response/truncated/轮数用尽|
|experiments|全部所选对照完成|存在未完成或失败，查JSON|启动异常|

日志走stderr，stdout留给协议或JSON；API Key不进入源码、工具结果、截图和学生共享文件。限制路径、UID、采样量和调用次数均属于提供的保护代码，不能以完成实验为由移除。
